# ⛵ Annapolis Boatyard Bash — Official Event Website

> **A Benefit for Annapolis Public Schools**  
> Friday, October 23, 2026 • 6:00 PM – 9:00 PM • Annapolis Marina

An elegant, modern, responsive one-page website built to announce, celebrate, and gather RSVPs for the Annapolis Boatyard Bash — an evening on the water featuring live acoustic music, local Chesapeake bites, drinks, and a silent charity auction benefiting local students and classrooms.

---

## 🌟 Key Features

- **Panoramic Waterfront Hero**: High-resolution maritime photography with crisp typographic hierarchy and direct RSVP triggers.
- **Event Information Grid**: Clear cards breaking down location, date, mission, admission, and school beneficiary information.
- **Interactive RSVP Modal**: Frictionless form allowing guests to reserve their spots with instant validation and dynamic toast confirmation.
- **Evening Schedule Timeline**: Hour-by-hour breakdown from sunset arrivals to auction close.
- **Interactive FAQ Accordion**: Expandable answers to common questions about parking, admission, dress code, and families.
- **100% Mobile Responsive**: Tested and optimized across smartphone, tablet, and desktop screens.

---

## 🛠️ Built With

- **HTML5**: Semantic tags, accessibility attributes, and SEO metadata.
- **CSS3**: Custom design system, modern CSS Grid & Flexbox, glassmorphic backdrops, smooth keyframe animations.
- **Vanilla JavaScript**: Lightweight, zero-dependency client logic for modal interactions and FAQ toggling.

## 🚀 Running Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com/your-username/boatyard-bash.git
   cd boatyard-bash
   ```
2. Open `index.html` in any web browser:
   - On Windows: double-click `index.html` or run `start index.html` in PowerShell.
   - Or use VS Code Live Server / Python HTTP server:
     ```bash
     python -m http.server 8080
     ```
